## Agent Rules

- Simplicity and utility are the core. Prefer the smallest change that solves the problem.
- Do not modify `.gitignore` unless explicitly asked.
- Keep edits scoped to the requested task; avoid opportunistic refactors or style-only churn.
- Preserve existing conventions, formatting, and naming unless a change is required for the fix.
- Ask before any destructive action (deleting files, removing large blocks, or resetting changes).
- Avoid generating placeholder content. If unsure, ask a concise question or state the assumption.
- Favor clarity over cleverness: readable code and comments only when they add real value.
